About translation quality

When Chrome supports Gemini Nano for the selected languages, it can use nearby dialogue for context. The standard translator works on individual text segments. Unicode SRTs keep their encoding. Older encodings export as UTF-8 so they can represent the target language. Review names, slang and dialogue that spans several cues before publishing.
