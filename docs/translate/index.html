About translation quality

Cueframe joins lines that continue the same thought, translates the phrase and fits it back into the original subtitle lines. It indexes the whole file to find related dialogue, including later mentions of names and expressions. The result shows which Chrome model processed your subtitle. Gemini Nano can translate or review dialogue in the languages it supports. Other language pairs use Chrome’s built-in Translator. Names, idioms and who did what can still need an editor’s eye. Timestamps, line breaks and formatting stay intact. Unicode SRTs keep their encoding. Older encodings export as UTF-8.
