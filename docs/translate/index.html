About translation quality

When Gemini Nano supports both languages, it uses nearby dialogue to translate in context. For English to Russian, Chrome translates from the original English. Check names, slang and how speakers address each other before publishing. Timestamps, line breaks and formatting stay intact. Unicode SRTs keep their encoding. Older encodings export as UTF-8.
